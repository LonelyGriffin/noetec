# Roadmap

Noetec is in **pre-alpha** and under active development. The full product vision — including the pillar features — is described in [docs/product/vision.md](docs/product/vision.md).

## Now

The foundation is being solidified: a local vault of plain Markdown files, a block/page editor, Markdown round-trip, an operation log (OpLog) with WAL persistence, and a unidirectional (Flux) data flow over `get_it` dependency injection.

## Next

User/device identity and file-based synchronization, followed by the block ecosystem — block references, backlinks, templates, task and query blocks, and table/kanban/calendar views.

## Later

Server-based synchronization and teams/roles, real-time collaboration (CRDT, peer-to-peer), and mobile polish (phone/tablet UI, built-in calendar, board mode).

> High-level and date-free. Detailed task tracking lives in the project's issue tracker.
