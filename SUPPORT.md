# Support

## Questions

Ask questions and discuss the project in [GitHub Discussions](https://github.com/LonelyGriffin/noetec/discussions).

## Reporting a bug

Open an [issue](https://github.com/LonelyGriffin/noetec/issues) and describe what you expected, what actually happened, and the steps to reproduce it.

## Reporting a security issue

Do **not** report security issues in public. See [SECURITY.md](SECURITY.md).
