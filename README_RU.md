## Что такое Noetec?

Noetec — кроссплатформенное приложение для заметок, которое сочетает открытость обычных файлов с удобством современного блочного редактора. Заметки хранятся в читаемых Markdown-файлах на вашем собственном диске, как в Obsidian, а редактор прячет разметку за дружелюбным интерфейсом в духе Notion.

Каждая заметка — это дерево типизированных блоков (абзацы, заголовки, списки, задачи и многое другое), и у каждого блока есть глобально уникальный идентификатор. Именно блочная структура позволяет точно ссылаться на фрагменты, синхронизировать данные и разрешать конфликты. Заодно она гарантирует, что ваши данные никогда не окажутся заперты в проприетарном формате.

Noetec работает по принципу **local-first**: данные хранятся и обрабатываются локально, приложение полностью работает офлайн, а сеть лишь расширяет возможности, но не обязательна. Если синхронизация всё-таки нужна, способ выбираете вы: через файлы (Git, Dropbox, …), через сервер (свой или облачный) или напрямую между устройствами.

## Для кого

- **Вы хотите сами распоряжаться своими данными.** Заметки остаются в обычных читаемых файлах под вашим контролем: без аккаунта, без закрытого хранилища и без привязки к поставщику.
- **Вы любите Markdown и self-hosting.** Подход, в центре которого файлы, хорошо уживается с Git, Dropbox и вашими собственными инструментами, а сервер синхронизации можно развернуть у себя.
- **Разработчики и ранние пользователи.** Открытое (AGPLv3) приложение на Flutter с чистой документированной архитектурой: её можно читать, изучать и расширять.

## Статус

Noetec находится на стадии **pre-alpha**: проект активно разрабатывается и пока не готов к ежедневному использованию для важных задач. API и форматы файлов могут меняться без предупреждения. Следить за ходом работ можно по [дорожной карте](docs/product/ROADMAP_RU.md), а если хотите помочь, загляните в [CONTRIBUTING_RU.md](docs/CONTRIBUTING_RU.md).

Привет! Я фронтенд-разработчик, а Noetec — мой экспериментальный проект, личное приложение для заметок. Когда проект окрепнет, присоединиться сможет любой желающий. Я также открыт к помощи ИИ, если её применяют с умом: сам активно им пользуюсь.

## Быстрый старт

```bash
flutter pub get
dart run build_runner build
flutter run
```

Нужен свежий Flutter SDK. Полная настройка окружения, включая git-хуки, описана в [CONTRIBUTING_RU.md](docs/CONTRIBUTING_RU.md).
