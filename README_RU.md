## Что такое Noetec?

Noetec — кроссплатформенное приложение для заметок, которое соединяет открытость обычных файлов с удобством современного блочного редактора. Ваши заметки лежат в читаемых Markdown-файлах на вашем собственном диске — подход Obsidian, — а редактор скрывает разметку за дружелюбным интерфейсом в духе Notion.

Каждая заметка — это дерево типизированных блоков (абзацы, заголовки, списки, задачи и не только), у каждого из которых есть глобально уникальный идентификатор. Именно блочная структура делает возможными точные ссылки, синхронизацию и разрешение конфликтов — и она же означает, что ваши данные никогда не заперты в проприетарном формате.

Noetec **локально-первичный (local-first)**: он полностью работает офлайн, а сеть — это улучшение, а не требование. Когда синхронизация нужна, вы выбираете способ сами: через файлы (Git, Dropbox, …), через сервер (собственный или хостинговый) или напрямую между устройствами.

## Для кого

- **Вы хотите владеть своими данными.** Заметки остаются в обычных читаемых файлах под вашим контролем — без аккаунта, без проприетарного хранилища, без привязки к вендору.
- **Вы любите Markdown и self-hosting.** Дизайн «сначала файлы», который хорошо сочетается с Git, Dropbox и вашими собственными инструментами, плюс серверная синхронизация, которую можно поднять самому.
- **Разработчики и ранние пользователи.** Открытое (AGPLv3) приложение на Flutter с чистой, документированной архитектурой, которую можно читать, изучать и расширять.

## Статус

Noetec в состоянии **pre-alpha**: проект активно разрабатывается и пока не готов для повседневного, критичного использования. API и форматы файлов могут меняться без предупреждения. Следите за прогрессом по [дорожной карте](ROADMAP_RU.md) и загляните в [CONTRIBUTING_RU.md](CONTRIBUTING_RU.md), если хотите помочь.

Привет! Я фронтенд-разработчик, и Noetec — мой экспериментальный проект, личное приложение для заметок. Присоединиться сможет любой, когда проект повзрослеет. Я также открыт к помощи ИИ там, где она применяется разумно, поскольку сам активно им пользуюсь.

## Быстрый старт

```bash
flutter pub get
dart run build_runner build
flutter run
```

Требуется свежий Flutter SDK (Dart 3.10+). Полная настройка — включая git-хуки — описана в [CONTRIBUTING_RU.md](CONTRIBUTING_RU.md).
